RMAP Microloan File Checklist

Cap Fund Academy · Certificate 4: RMAP Microlender Operations · capfundacademy.com

Every closed RMAP microloan must have a complete loan file. Use this checklist at origination and again at the annual file review. Check each item as present and legible. Note "N/A" only for items that genuinely do not apply with a written explanation.

Borrower Name
Loan Number
Disbursement Date
Original Loan Amount
File Reviewed By / Date

Part 1 — Pre-Loan / Underwriting Documents

✓DocumentPresent?Date / Notes
Completed loan application (signed and dated by borrower)
Borrower business plan or project narrative
Personal financial statement — borrower
Personal financial statement — guarantor(s) (if applicable)
Business financial statements: 2–3 years tax returns or CPA-prepared P&Ls (existing businesses)
Cash flow projection / repayment analysis
Credit report(s) — borrower (and guarantors if applicable)
Credit elsewhere determination — denial letter(s) from bank(s) or written credit elsewhere memo
Rural area verification — USDA RUCA code or rural designation documentation for borrower's business location
10 FTE or fewer employees verification — borrower certification or payroll documentation
Environmental screening worksheet (completed, signed, dated)
Phase I Environmental Site Assessment (if real property involved as collateral)
Civil rights — voluntary borrower demographic data form
Ineligible use screen — confirmation loan purpose is not on RMAP ineligible use list (7 CFR 4280.326)

Part 2 — Loan Approval Documents

✓DocumentPresent?Date / Notes
Loan committee approval minutes (dated, lists all members present, records vote)
Approval letter or commitment letter (signed by authorized officer)
Promissory note (signed by borrower and all guarantors)
Loan agreement / security agreement (signed)
UCC-1 financing statement (filed with appropriate state office)
Deed of trust / mortgage (if real property collateral — recorded copy)
Business insurance certificate (property, general liability) — lender listed as additional insured
Life insurance certificate (if required by loan policy — lender as beneficiary)
Conflict of interest disclosure (if any board/staff relationship to borrower)

Part 3 — Adverse Action (Denied Applications)

Complete only for denied applications. Approved loans: mark N/A.

✓DocumentPresent?Date / Notes
Written adverse action notice (sent within 30 days of decision)
Adverse action notice includes specific reasons for denial (not generic)
Proof of delivery (certified mail receipt or email confirmation)

Part 4 — Post-Closing / Servicing Documents

✓DocumentPresent?Date / Notes
Disbursement confirmation (wire record, check copy, or ACH confirmation)
Payment history / ledger card (current through review date)
Annual financial review notes (required for loans outstanding >12 months)
Job creation/retention documentation — 12-month follow-up form
Modification / extension / workout agreement (if applicable)
Collection correspondence log (if delinquent)
Default notice (if applicable)
Charge-off documentation and board authorization (if applicable)
